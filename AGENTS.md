# Repository instructions

- Use `SPEC.md` as the approved source of truth. Do not invent requirements,
  editorial approvals, course coverage or validation results.
- For a completed development increment, run the relevant checks, push its PR,
  and merge after its checks pass. Do not leave completed PRs as drafts.
- After merging, delete the merged GitHub feature branch and its local branch.
  Verify its commits are included in `main` first; preserve any unmerged work.
